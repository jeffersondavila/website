01 — Perfil

Qué construyo

Trabajo sobre plataformas empresariales .NET: soluciones ERP y CRM donde el negocio vive en los procesos fiscales, contables, de cobros y de facturación, y donde un error de cálculo o una consulta lenta se notan el mismo día.

Mi trabajo va del análisis técnico del requerimiento hasta la funcionalidad en producción: diseño de la solución, implementación en C# y SQL Server, integración con servicios externos vía REST y SOAP, optimización de consultas y procedimientos almacenados, y diagnóstico de incidencias en funcionalidades críticas.

Aplico principios SOLID, patrones de diseño y buenas prácticas de arquitectura, y complemento esa experiencia con una Maestría en Seguridad Informática y de Sistemas, con foco en seguridad aplicada al desarrollo de software.

TestBlog

API REST en ASP.NET Core

Implementación de referencia de una API REST para un blog, pensada para practicar el camino completo: modelo de datos, contrato documentado y consumo desde clientes distintos sin escribir el cliente HTTP a mano.

Qué construí

  • API en ASP.NET Core 8 con controladores, DTOs y capa de servicio, y persistencia con Entity Framework Core sobre SQL Server.
  • Pruebas unitarias del servicio con proveedor en memoria y reporte de cobertura.
  • Contrato OpenAPI expuesto con Swagger y clientes tipados generados con NSwag.
  • Cliente Blazor WebAssembly y un cliente aparte para consumo desde un servicio externo.
  • C#

  • ASP.NET Core
  • Entity Framework Core

  • OpenAPI / Swagger

Blog personal

Plataforma propia · En desarrollo

Un blog no necesita tres repositorios; lo separé así a propósito, para tratarlo como un proyecto de ingeniería completo y dejar por escrito las decisiones, el estado y el roadmap junto al código.

Qué construí

  • Sitio público en React, TypeScript y Vite, con sistema de diseño propio, búsqueda, filtros por etiqueta y render de Markdown saneado.
  • API en FastAPI y PostgreSQL con configuración tipada, logging estructurado, migraciones con Alembic, autenticación administrativa y pruebas.
  • Almacenamiento de objetos tras una interfaz común: MinIO en local, S3 en la nube.
  • Entorno local reproducible con Docker Compose, más ADR, runbooks y estado del proyecto versionados.

canvas-scraper

Automatización sobre API REST

Archivar a mano el material de cada curso de la maestría es lento y se olvida. Esta herramienta lo descarga desde la API oficial de Canvas LMS y lo deja consultable sin conexión.

Qué construí

  • Consumo paginado de la API de Canvas en cuatro fases: módulos, tareas, repositorio de archivos y entregas con su retroalimentación.
  • Reescritura del HTML descargado a rutas locales para que páginas y foros se vean sin conexión.
  • Configuración por archivo y variables de entorno, con el token fuera del repositorio, y pruebas automatizadas.
